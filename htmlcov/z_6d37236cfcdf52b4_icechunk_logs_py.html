1"""Which Icechunk warnings canVODpy shows. 

2 

3Two Icechunk warnings that don't apply to canVODpy's stores are hidden; 

4every other Icechunk warning is shown. ``ICECHUNK_LOG``, when set, 

5replaces this filter. 

6 

7- icechunk_arrow_object_store, on every store opened: the local file system 

8 is not safe for concurrent commits. canVODpy runs every commit under 

9 ``commit_lock``. 

10- icechunk_storage::readback, once per process: without 

11 ``unsafe_use_metadata``, a lost reply to a conditional write may surface 

12 as a spurious conflict. Icechunk's local file system storage can't store 

13 that metadata (it refuses ``unsafe_use_metadata=True``) and makes one try 

14 per write, so no reply is lost and retried. 

15""" 

16

26) 

27 

28_applied = False 

29 

30 

31def apply_icechunk_log_filter() -> None: 

32 """Set the filter once per process, unless ``ICECHUNK_LOG`` is set. 

33 

34 Called on import by every package that opens stores

38 if _applied or "ICECHUNK_LOG" in os.environ:
